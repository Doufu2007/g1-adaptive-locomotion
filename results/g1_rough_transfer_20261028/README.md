# Rough-transfer evidence (2026-10-28)

This directory preserves the compact evidence record for the earlier rough-terrain transfer experiment. It is included to make the project history auditable; it is not presented as a positive confirmation of the main stability claim.

The locked comparison reported 13/90 completed episodes for the learned-phase arm (DE) versus 9/90 for the matched fixed-clock arm (DC), a +4.44 percentage-point completion difference. The confidence interval included zero and Holm-adjusted comparisons did not establish superiority. The record also reports no confirmed push-recovery advantage and no matched feedback-removal intervention.

The public files contain the preregistration, design, claim/evidence map, domain audit, complete aggregate analysis, and result narrative. Raw rollout arrays remain outside this repository. Paths are anonymized; hashes in historical reports continue to bind the sealed originals. Original and public-copy hashes are listed in [the provenance manifest](../../verification/phase_evidence_provenance.json).
