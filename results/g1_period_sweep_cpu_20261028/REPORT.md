# 可复现后端上的 A1 复检（2026-10-29）

## 为什么换后端

GPU 后端不可复现：同一脚本、同一 seed、逐位相同的初始状态，两次运行在**第一次 `env.step()`** 就分叉（把策略摘掉、喂固定动作序列也一样）。详见 `results/g1_nondeterminism_20261028/NOTES.md`。
CPU 后端逐位可复现（同一完整回合两次运行，所有原始数组 SHA256 相同）。本报告全部数字来自 **CPU 后端**。

- 地图：S 轮评测图 `20264701`–`20264703`（训练图 `20264601`–`20264603`，无重叠）

- 合计：每臂 90 回合，配对 90 对，缺失 0

## 判决（按预注册 §5 判决表）

主终点 p = 0.743 ≥ 0.05，且点差 +3.33 pp < 预注册的 +10 pp 门槛 ⇒ **判决「不支持 A1」**。

允许的措辞只有："在新地图/新后端上未见显著差异（+3.33 pp，95% CI [−3.27, +9.93]）"。
