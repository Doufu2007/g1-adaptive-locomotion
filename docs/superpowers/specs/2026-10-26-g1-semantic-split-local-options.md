2026-10-26 用户追问“完全没法用本机吗”。答复：**可以用本机，不能把 22 GB 的保守准入阈值当作实测最低显存要求。** 尚未实测本次平地任务的最大并行数和训练速度。

本项目已有真实历史证据：`phasor/results/phasor_local_pilot_20261020/smoke_train_1024env_51iter.json`，任务 `Unitree-G1-Rough-PHASOR`，1,024 环境、51 更新、280.715 秒，平均 5.504 秒／更新。原始 JSON 的本次副本及 SHA 存在 `results/g1_semantic_split_20261026/verification/`。

这些数字仅为历史粗糙地形、不同 phase 控制器的外推，不是当前平地测量；不含评估、四组 pilot、竞争负载和持续运行降频。若第一行 pilot 也是 1,024 环境×1,000 更新，四组额外约 6.1 小时。若第二行要求 pilot 也保持原采样量，应使用每组 4,000 更新，额外约 24.5 小时。

无论采用哪一行，四组 Actor、语义／随机分组、Critic、公平性校验和评估仍保持一致。它们是新的预算方案，需要记录 protocol amendment，使用独立目录；不得把 1,024 环境 smoke 当作已完成原计划 4,096 环境 pilot。

当前 GPU 实测利用率约 88%，仍有 G1 phase probe 与另一个研究任务运行；没有停止它们。下一步应先确定预算，再在 GPU 可用时用本次平地任务测量短 pilot、显存和迭代速度，修正耗时外推。用户偏好已异步询问，尚未据此更改已冻结的主协议。
